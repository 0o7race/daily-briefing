今天重点论文可以选 S-Agent。它试图解决一个很具体的问题：视觉语言模型看图可以回答问题，但在多视角、视频和三维空间里，模型常常没有稳定的场景状态。S-Agent 的做法不是让 VLM 一口气完成所有空间推理，而是把它当成语义规划器。模型先判断需要什么证据，再调用 2D grounding、3D 几何、计数、测量、朝向和相对位置等工具，同时维护 Scene Memory 和 Agent Memory。这个思路很重要，因为空间智能不是单帧识别，而是连续证据累积。对机器人、AR、自动驾驶、仓库巡检和数字孪生来说，工具、状态和记忆可能比单纯扩大模型更直接有用。

再补一个前沿概念：世界模型的 persistent state core。今天另一篇论文指出，很多视频世界模型可以生成看起来连续的画面，但镜头移开后，物体和事件未必真的继续演化。比如一个球滚出画面，镜头回来时，模型可能只是把球恢复到离开时的状态，而不是让它在看不见期间继续运动。这对内容生成也许还能接受，但对机器人规划就很危险。真正有用的世界模型，需要维护一个独立于观察的内部物理状态，而不只是预测下一帧长什么样。
